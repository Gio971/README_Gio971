## Hi there 👋


My main projects are kept in private repositories, so you won't find much code here. Instead, this README summarizes what I'm working on, the problems I'm solving, and the tools and technologies I use to ship real products.


### 🎟️ Premio — Next-Gen Secure Ticketing Platform
*Full-stack developer & creator of a production ticketing system for sports and live entertainment.*

- **Core Mission:** Provide tamper-proof, fraud-resistant digital ticketing with dynamic QR code verification, instant check-in, and fair-exchange resale, while keeping the user experience 100% web2-friendly (zero wallet setup, zero gas fees).
- **Architecture:** Client-side React 18 SPA coupled with a robust Supabase backend (PostgreSQL RPCs, strict RLS, Deno Edge Functions) and Polygon EVM smart contracts for ticket lifecycle management and minting relayers.
- **Key Features:** Gasless custodial wallet abstraction, offline-capable scanner PWA, Stripe payment and Connect infrastructure, real-time analytics, and automated sport schedule ingestion.
- **Technologies:** `React` · `TypeScript` · `Vite` · `Tailwind CSS` · `PostgreSQL` · `Deno` · `Solidity` · `Polygon` · `Stripe`

  

### 📈 Unicity — Intelligent Portfolio Management & Financial Analytics

*Full-stack developer & creator of an investment tracking and financial asset intelligence platform.*

- **Core Mission:** Provide investors with a consolidated view of multi-asset wealth (stocks, ETFs, crypto), offering real-time portfolio valuation, risk and allocation breakdowns, and actionable performance insights through an intuitive, data-driven interface.
- **Architecture:** Decoupled modern stack pairing a high-performance React 18 / TypeScript SPA (Vite, TanStack Query, shadcn/ui) with a containerized FastAPI (Python) asynchronous REST API, backed by PostgreSQL and SQLAlchemy with Alembic migrations.
- **Key Features:** Multi-portfolio tracking, automated market data ingestion, dynamic asset allocation visualizations, historical return metrics, JWT authentication, and Dockerized deployment.
- **Technologies:** `React` · `TypeScript` · `Vite` · `Tailwind CSS` · `FastAPI` · `Python` · `PostgreSQL` · `SQLAlchemy` · `Docker` · `Pandas`
